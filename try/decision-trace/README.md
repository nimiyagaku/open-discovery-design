# Failure: 「なんでこうしたんだっけ？」をAIが綺麗なStoryで埋めた

## What happened

Decisionは残っていても、当時のContextが断片化していると、後からAIが自然なStoryを補完することがあります。

問題は一度の誤りより、そのStoryが次のDecisionの前提になることです。

## Minimum Fork

全部のDecisionではなく、誤って再利用されたときの影響が大きいものだけ [`DECISION.md`](./DECISION.md) で残します。

## Watch

数日後にAIへ「なぜこのDecisionになった？」と聞き、元のObservation / Sourceまで辿れるか確認します。

完全な履歴より、必要になったときの帰り道を優先します。
