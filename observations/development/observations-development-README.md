# Development Observations

このDirectoryには、ODDのDevelopment中に見えてきたObservationや、まだConcept / Practiceとして確定していない構想を置きます。

ここにあるKnowledgeは、完成したTheoryやODDのCurrent Foundationではありません。

> **Observation before Theory.**

実際のProduct Development、AI Team運用、Knowledge管理、Role / Context設計の中で起きたことを残し、必要なら後からConcept / Practiceへ育てます。育たずにそのまま残る、変わる、捨てることもあります。

## Current observations

### [Friend Layer / Stepping Outside the Optimization Game](./friend-layer.md)

**Status:** Observation / Candidate Practice  
**Lifecycle:** Exploring

Product Ownerとしての通常位置から一時的に離れ、自分・Project・Productを観察対象に回すCognitive RepositioningのObservationです。

Role Separationだけでは全員が同じOptimization Goalの中に残る可能性があるため、改善・評価・結論を目的としないFriend Roleを試しています。

これはIndependent External Perspectiveを得る仕組みではありません。

### [ODD Generalization Notes](./odd-generalization.md)

**Status:** Exploring / Hypothesis

ODDに、Ideas固有のPractice、Human–AI systemで繰り返すかもしれないPattern、さらに一般化できるかもしれない構造が混在している可能性を検討する構想です。

現在は、次の3層を仮置きしています。

```text
Practice
  ↓ repeated structure?
Pattern
  ↓ survives beyond Human–AI?
Model
```

これはODDのFoundationを定義するDocumentではありません。

一般化するときも、Conceptが生まれたFailure、Product-specific pressure、Revisionの傷跡を消さず、元のRealityまで辿れる状態を残します。

> **This is not the foundation of ODD.**  
> It is a possible structure observed after the practices already existed.

## How to read this directory

このDirectoryのObservationは、次のように扱います。

- Documentが存在することをAdoptedの証拠にしない
- Exploring / Hypothesis / CandidateなどのStatusを保つ
- Current Conceptへ自動的に一般化しない
- 新しいObservationを既存の構想へ無理に当てはめない
- Realityが違えば、Document側を修正・分岐・破棄する

特に `odd-generalization.md` は、ODDをすべて一つのTheoryで説明するためのLensとして使いません。
