# Reality First

**Epistemic Status:** Operational Principle / Candidate  
**Lifecycle:** Current  
**Summary:** Dialogue、Theory、Rule、過去のInterpretationをRealityより上位に置かないための考え方。

> **Observation before Theory.**  
> **Reality before Story.**

## Reality Can Revise Meaning

Session内で納得できたInterpretationもFinal Truthではありません。Realityはそれを Strengthen / Modify / Complicate / Suspend / Reject できます。

Realityには、User Behavior、Prototype Reaction、Implementation Constraint、Failure、Business Constraint、Conversation、Action Result、Product Owner Reaction、Time-based Change、External Environmentなどが含まれます。

## Cognitive Repositioning ≠ External Reality

Cognitive PositionをSelf / Project / Productの通常Boundaryから一時的に外へ移すことで、新しいObservationが生じることがあります。

ただし、その位置が同じHuman–AI Systemの中で作られているなら、それをIndependent External Realityとは扱いません。

> **A different cognitive position is not automatically an external perspective.**

Role-play、Reviewer、Specialist、Friend Layerなどから得たObservationはUsefulですが、実在の他者、User Behavior、Action Result、External Environmentなどから返るRealityとは区別します。

両者を混同せず、どこから生じたObservationなのかを保持します。

## Reality First ≠ Interpretation-Free

Observation自体にもInterpretationは混ざります。Reality Firstは「純粋な客観Realityを取得できる」という主張ではありません。

ObservationとExplanationを区別し、Interpretationを修正可能に保つことが重要です。

## Reality First ≠ Anti-Theory

TheoryやPrincipleは探索を助けます。ただしTheoryにRealityを合わせません。

> **Rules do not outrank Reality.**

Ruleに従った結果Productが壊れるなら、Rule側を疑います。

## Reality First ≠ Immediate Action

Realityへ接続することは、すぐ行動することとも同義ではありません。Reality proximityがLoadやFearを増やす場合もあります。

## Provisionality

HumanのMeaning、AIのInterpretation、Design Decision、Reviewer Judgment、System Rule、ODD自体もProvisionalです。

Provisionalだから無価値なのではなく、Revision可能性を残したまま使います。

## Lineage

### Origin

Reality First did not begin only as a rule for testing Theory.

Early Ideas treated exploration as something that should eventually meet life outside Dialogue: Action, Creation, Product Work, Decision, Behavior, or other Reality where new value can be created.

As Product Development continued, Reality also became the place where Interpretation, Rule, Rubric, and Design Assumption could be revised.

### What Changed This

Repeated calibration made the principle more operational.

A Response can violate a Current Rule and still produce a Good Experience. In that case, the Response should not automatically be corrected to fit the Rule; the Rule / Rubric itself becomes an object of investigation.

Reality First therefore came to apply not only to Human Meaning or Hypothesis, but also to the System that evaluates them.

### What This Is Not

Reality First is not anti-Theory, and it is not a demand for Immediate Action.

It also does not treat Reality only as a judge that confirms or rejects ideas. Reality can be both:

- where exploration creates value
- where current Interpretation or Design is revised
