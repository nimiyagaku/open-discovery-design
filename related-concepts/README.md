# Related Concepts

**Epistemic Status:** Navigation / Reference
**Lifecycle:** Exploring
**Summary:** ODDから既存のConceptや研究領域へ辿るための軽量なBridge。

ODDには、既存の研究・Practiceと近いConceptがあります。

このPageの目的は、ODDを学術的に証明することでも、網羅的なLiterature Reviewを維持することでもありません。

> **ODDから外のKnowledgeへ辿るための入口です。**

気になるConceptがあれば、その名前から論文・書籍・解説へ進んでください。AIに「このConceptとODDの違いを説明して」「代表的な研究を挙げて」と聞いても構いません。

## Read This Carefully

Related Conceptは、ODDのOriginやInfluenceを意味しません。

> **Related ≠ Equivalent ≠ Derived From**  
> **Similarity is not lineage.**

ODDの多くは、IdeasのProduct Developmentで実際に起きたProblem、Observation、Practiceから先に生まれました。後から似たConceptが見つかった場合も、その類似だけで系譜を主張しません。

また、下のRelationは確定したOntologyではありません。理解のためのCandidate Bridgeです。

## Co-Explorer

近くを探索しやすいConcept:

- **Sensemaking** — 曖昧な状況に意味を与え、次のActionにつなげる過程を見るLens。
- **Participatory Sense-Making** — Meaningが個人内部だけでなくInteractionの中でも形成されるというLens。
- **Human–AI Co-Creation / Mixed-Initiative Interaction** — HumanとAIの双方がContributionやInitiativeを持つInteraction Design。
- **Scaffolding** — Humanが自力では届きにくい探索や学習を支える足場。
- **Grounding / Common Ground** — Interactionの中で「何を共有できているか」を成立させる考え方。

→ [Co-Explorer](../concepts/co-explorer.md)

## Meaning Authority

近くを探索しやすいConcept:

- **Agency** — Humanが自分のActionやDecisionへ関与できること。
- **Autonomy** — 外部Influenceがある中でも自己決定を保つこと。
- **Shared Control** — HumanとSystemの間でControlをどう配分するか。
- **Appropriate Reliance** — AIを過信も過小評価もせず、状況に応じて頼る問題。
- **Human–AI Interaction Guidelines** — AIのError、Correction、Control、AdaptationをHuman-centeredに扱うDesign Lens。

ODDでは、これらと重なる部分があっても、中心を **Influenceの排除ではなくMeaningのRevision可能性** に置いています。

→ [Meaning Authority](../concepts/meaning-authority.md)

## Reality First

近くを探索しやすいConcept:

- **Reflective Practice** — Actionの中で状況と対話しながらPracticeを更新する考え方。
- **Situated Action / Situated Cognition** — PlanやKnowledgeをContextから切り離さず、実際のSituationの中で見るLens。
- **Sensemaking** — ActionとInterpretationが循環しながらMeaningを作る考え方。
- **Research through Design** — Design ArtifactやMakingを通じてKnowledgeを生むPractice。
- **Action Research** — ActionとReflectionを往復しながらPracticeを更新する研究・実践系譜。

ODDのReality Firstは、Realityを単なる検証装置ではなく、**Meaningを修正し、同時に新しいValueが生まれる場所**として扱います。

→ [Reality First](../concepts/reality-first.md)

## Human Fluctuation

近くを探索しやすいConcept:

- **Situated Cognition** — HumanのCognitionやBehaviorをSituationとの関係で見るLens。
- **Metacognition** — 自分のThinking、Confidence、ReadinessなどをMonitor / Controlする考え方。
- **Narrative Identity** — SelfやMeaningを固定値ではなく、更新されるStoryとして見るLens。
- **Motivation / Readiness** — InterestがあってもActionへ進める状態とは限らない、という区別に関係する領域。
- **State-dependent Behavior** — Current StateによってBehaviorやDecisionが変わることを見るLens。

→ [Human Fluctuation](../concepts/human-fluctuation.md)

## AI Product Team / Handoff / Knowledge

近くを探索しやすいConcept:

- **Distributed Cognition** — Cognitionを一人の頭の中だけでなく、人・Artifact・Environmentへ分散したSystemとして見るLens。
- **Boundary Objects** — 異なる視点を持つActorの間で、同一性を保ちながら共有されるArtifact。
- **Cognitive Offloading** — MemoryやThinkingの一部をExternal Artifactへ移し、Cognitive Demandを変えること。
- **Grounding / Common Ground** — HandoffやConversationで何を共有できているかを成立させる問題。
- **Context Engineering** — AI Systemに何をContextとして渡し、何を渡さないかを設計する現在進行形のPractice領域。
- **Separation of Concerns / Independent Review** — ProductionとEvaluationなどの認知的位置を分けるSoftware / Team DesignのLens。

ODDではTask Distributionだけでなく、**Role Allocation + Context Allocation**、Session ContextとCurrent Knowledgeの分離、Fresh ContextをFeatureとして使うことなどを探索しています。

→ [AI Product Team](../practices/ai-product-team.md)  
→ [Handoff](../practices/handoff.md)

近くを探索しやすいConcept:

- **Research through Design**

## A Note on Literature

Public ODDでは、現時点で網羅的なBibliographyを維持しません。

理由は、Repositoryを読むために大量のLiteratureを前提にしたくないことと、Related Concept自体が今後も増減・修正されるためです。

論文や書籍まで読みたい場合は、このPageのConcept名を入口にしてください。

AIへ渡す場合は、たとえば次のように聞けます。

- 「Meaning Authorityに近い既存Conceptを比較して。ODDと同一視しないでください。」
- 「Distributed CognitionからAI Product Teamを読むと、何が説明できて何が説明できませんか？」
- 「Reality FirstとReflective Practiceの共通点と違いを、代表的な文献を挙げて説明してください。」
- 「このRelated Concepts Pageに誤った対応や過剰な類似がないか批判してください。」

> **外部KnowledgeはODDを正当化するためだけに使いません。ODDを修正する材料にもなります。**
